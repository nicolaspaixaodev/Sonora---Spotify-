# Sonora

Tela de login de um player de música, feita com HTML, CSS e JavaScript puros.

**Acesse:** _(link do GitHub Pages entra aqui)_

## O que tem

- Layout responsivo, tema escuro
- Botão de mostrar/ocultar senha
- Validação de campos com mensagens em português
- Erros somem enquanto o usuário digita
- Redirecionamento após validar

## Aviso

Projeto de estudo. **Não há autenticação real** — nada é enviado nem
armazenado, e a validação existe apenas para experiência de uso.
Autenticação de verdade acontece no servidor, nunca no navegador.

## Estrutura

```
index.html   tela de login
login.css    estilos
login.js     validação e interações
app.html     placeholder pós-login
```
